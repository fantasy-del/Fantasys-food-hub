# Fantasys-food-hub
A fully responsive restaurant website built with HTML,CSS AND JAVESCRIPT as part of a web development academic project.
## features
- **Home Section:** Features a welcoming hero banner and introduction to the restaurant.
- **About section:** outlines the restaurants background,history,,mission and vision.\
- **Menu & services:** built using css grid and flexbox to display food items,services and prices.
- **Contact:** includes business details and a fully functional interactive contact form.

  HTML5
  CSS
  JAVASCRIPT
